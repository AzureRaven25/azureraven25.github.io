GT Movies Store

An online movie shop in Django 5. I typed every line myself instead of copying the book’s repository, then added a feature the book never covers.

Read the code on GitHub
When
January 2026
Built with
Django 5, Python, SQLite, HTML and CSS, hosted on PythonAnywhere
Based on
Django 5 for the Impatient, by Daniel Correa and Greg Lim
Scope
21 features, 3 kinds of user, every line typed by hand

What it is

GT Movies Store works like an online movie marketplace. People browse a curated library, buy movies and write reviews, while administrators keep full control of the data and the moderation.

I built it alongside the textbook, but I typed every line by hand rather than copying from its GitHub repository. By the middle chapters I could guess the next step before reading it.

The review reporting feature is not in the book at all. I designed and built it myself. Anyone can report a review, and it leaves public view right away. Writing a feature with no instructions was how I checked that the framework had actually sunk in.

The shop

Browsing and signing in, movie pages and reviews, the cart and orders, and the about page and admin.

What I learned

This was my first real Django application. Typing every line paid off. By the end I could reason about URL routing, views, template inheritance and the ORM without opening the book, and building the reporting feature on my own showed I understood the framework rather than just following steps.
