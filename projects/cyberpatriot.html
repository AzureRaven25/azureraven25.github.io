How a round works

Each round hands the team virtual machines running Ubuntu, Fedora, Windows 10 and Windows Server, each one broken on purpose. Unauthorized users, weak passwords, services that should be off, open firewalls, malware that hides itself. Points come in live as you find and fix each problem before time runs out.

Platinum is the top regular tier, and staying there takes strong scores in every qualifying round. We reached the National Semifinals three years in a row.

What I did on the machines

Linux
User audits, service cleanup, UFW and iptables rules, SSH hardening and file permissions on Ubuntu, Fedora and Debian
Windows
Local Security Policy, Group Policy, account control, service audits and registry hardening on Windows 10 and Server
Automation
Bash and PowerShell scripts that found misconfigurations faster than checking by hand
Forensics
Log analysis and artifact recovery for the forensics questions
Networks
Cisco Packet Tracer and Wireshark

Teaching the club

I ran the club’s weekly security sessions for more than 30 students. I wrote the lessons, led hands-on labs on finding, exploiting and fixing vulnerabilities, and coached members through practice rounds before each competition.
